# Журнал типовых инцидентов

- Неиспользуемая переменная: проверьте журнал шага Static analysis.
- Недостаточные права публикации: проверьте журнал deploy-pages и права токена.
- Битая ссылка: проверьте журнал шага Build documentation.
- Прежняя версия после успешного деплоя: проверьте URL окружения, коммит и кэш браузера.

## Правило разбора

Укажите симптом, затронутый компонент, доказательство из журнала, причину, исправление и проверку восстановления.
